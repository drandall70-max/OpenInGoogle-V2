Beginner Guide: Create Your Google Credentials File

1. Go to https://console.cloud.google.com/
2. Create or select a project, for example OpenInGoogle Personal.
3. Enable the Google Drive API:
   https://console.cloud.google.com/apis/library/drive.googleapis.com
4. Configure OAuth consent screen.
5. Add your own Google email as a test user if Google asks.
6. Go to https://console.cloud.google.com/apis/credentials
7. Create Credentials > OAuth client ID > Desktop app.
8. Download the JSON file.
9. Rename it exactly to credentials.json.
10. Save it here:
    %APPDATA%\OpenInGoogle\credentials.json

Do not share credentials.json or token.json.
