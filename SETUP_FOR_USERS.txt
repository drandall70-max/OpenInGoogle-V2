OpenInGoogle User Setup

WHAT GETS INSTALLED

- OpenInGoogle app
- Start Menu shortcuts
- Optional default app handling for Office files
- Credentials folder at %APPDATA%\OpenInGoogle
- Uninstall entry in Windows Installed Apps

DOUBLE-CLICK WORKFLOW

The goal is:
- Double-click Office files to open them in Google Docs, Sheets, or Slides.
- Right-click and use Open with to use Microsoft Office instead.

WINDOWS 11 NOTE

Windows 11 may require you to confirm the default app manually:
1. Right-click a .docx, .xlsx, or .pptx file.
2. Choose Open with > Choose another app.
3. Select OpenInGoogle.
4. Choose Always use this app.
5. Click OK.

GOOGLE CREDENTIAL SETUP

Use Start Menu > OpenInGoogle > Setup Google Credentials.

Your credential file must be saved as:
%APPDATA%\OpenInGoogle\credentials.json

UNINSTALL

Settings > Apps > Installed apps > OpenInGoogle > Uninstall
